# Telegram Offers — управляющий бот без трекера

Запуск: `python bot_runner.py`. Установка, формат списков и команды: [BOT_SETUP.md](BOT_SETUP.md).

Вход: `@username Scared Cat #16951 425 gram`.
Выход: `jdcsnjdc Scared Cat #16951 425 gram ru`.

Автоматический язык по отображаемому имени: cn / ar / ru. Ручная правка и подтверждение перед постановкой в очередь. До 10 аккаунтов, общая очередь с интервалом 15 секунд, постоянная история получателей и логи. Цена используется как введена, без скидки. Трекера и графического интерфейса в этой сборке нет.

Свою папку `data` перенесите из предыдущей версии, сохранив историю и сессии.

Можно переслать целиком сообщение «Результаты» из парсера и следующим сообщением задать общую цену `425 gram`. Бот извлечёт получателей и NFT, покажет черновик с возможностью исправить язык. `/price 425 gram` меняет цену всех строк черновика.
