# Telegram Gifts Desktop

Обложка главного экрана: нажмите «Выбрать обложку» и укажите сохранённое
изображение PNG/JPEG/WebP. Оно сохранится в `data/banner.png` и будет загружаться
при следующих запусках. Картинка служит фоном окна под кнопками и полями.
Пропорции сохраняются; края обрезаются под размер окна. Фон слегка затемняется
для читаемости, журнал сохраняет сплошной тёмный фон.

Окно на Python/Tkinter: трекер подарков, до 10 Telegram-аккаунтов, назначение
предложений по кругу, логи и отправка владельцу без группы и без бота.

## Запуск на компьютере

Нужен Python 3.12 с Tkinter. На Windows установите официальный Python с Tcl/Tk;
на Linux может потребоваться пакет `python3-tk`.

```sh
python -m venv .venv
# Linux/macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python desktop.py
# Windows вместо .venv/bin/python используйте .venv\Scripts\python.exe
```

Введите свой API ID и API Hash с my.telegram.org. Для каждого аккаунта введите
телефон, нажмите «Получить код / сессия», затем введите код Telegram и при
необходимости пароль 2FA, нажмите «Войти». Сохранённую сессию можно подключить
той же кнопкой без повторного входа. При запуске нужно подключать нужные слоты.
Вместо ввода API-параметров можно задать TG_API_ID и TG_API_HASH в окружении.
Кнопка «Выйти» в строке аккаунта завершает его сессию Telegram. Перед выходом
текущий скан останавливается; остальные аккаунты и история подарков сохраняются.
Для повторного входа запросите новый код. Если Telegram не подтвердил выход,
аккаунт остаётся в списке и ошибка отображается в журнале.

Начните с предпросмотра. Для реальной отправки включите соответствующий флажок
и запустите заново. Первый полный проход каждого запуска запоминает текущие
подарки без предложений и отправки. Со второго прохода обрабатываются только
новые ссылки подарков, отсутствовавшие в первом проходе и сохранённой истории.
База первого прохода сохраняется после перезапуска. Первый проход не отмечает
владельцев как получивших предложение и не сдвигает очередь аккаунтов. Если
запросы коллекций завершились с ошибками, отправка остаётся выключенной до
полного прохода без ошибок. В предпросмотре действует тот же прогрев.
Пауза останавливает следующие операции, но не отменяет уже
выполняющийся запрос. Аккаунты назначаются 1 → 2 → … → последний → 1 среди
подключённых слотов. Один владелец получает только одно предложение: следующие
его подарки пропускаются. Ссылки имеют вид https://t.me/nft/Slug.

Сообщение: `jdcsnjdc Mirage Lamp #333 380 stars` при исходной цене 400 Stars.
Используется название коллекции и номер подарка; ссылки и окончания ru нет.
Цена умножается на 0.95 и округляется вниз. Запрос рынка использует stars_only=True; дополнительно проверяется валюта каждого лота.
Лоты в TON, смешанные цены и дробные Stars пропускаются.
Это текстовое сообщение владельцу; приложение не выполняет оплату и не
гарантирует, что сторонний бот распознает команду в чужом личном чате.

В `watcher_core.py` сохранены коллекции и фильтры исходного трекера. Владельцы
запоминаются по Telegram user ID при назначении предложения, до отправки.
Память сохраняется после перезапуска и не зависит от смены username. Старая
история автоматически переносится по username, поскольку раньше ID не сохранялся;
это консервативная блокировка, которая может затронуть нового владельца прежнего
username. Неудачные отправки тоже сохраняются без автоматического повтора.
Предпросмотр и
отправка используют разные базы, поэтому предпросмотр не блокирует отправку.
`data/` содержит сессии, журнал activity.log и SQLite-базы с назначениями и
статусами. Эти файлы приватные: не публикуйте их. Повторная отправка одного
подарка исключена и после перезапуска. Ошибки, прерванные отправки и ограничения
не повторяются автоматически: статус pending может означать неопределённый
результат при отключении во время запроса. Проверяйте чат перед ручным повтором.
При FloodWait сканирование или отправка останавливаются без обхода через другой
аккаунт. Если проверка платных сообщений недоступна, владелец пропускается до
следующего прохода. Временные ошибки получения владельца не отмечают подарок
окончательно просмотренным.

## Проверки

```sh
.venv/bin/python -m unittest -v
```

Проверяются скидка, валюты, назначение аккаунтов, сохранение состояния и
интеграция трекера с отправкой через подменённые Telegram-клиенты. Реальный
Telegram требует ваших аккаунтов и доступ к его сети. Графический запуск требует
экрана; облачная консоль без DISPLAY не показывает окно.
