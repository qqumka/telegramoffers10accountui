# Telegram Gifts Desktop

Окно на Python/Tkinter: трекер подарков, до 10 Telegram-аккаунтов, назначение
предложений по кругу, логи и отправка владельцу без группы и без бота.

## Запуск на компьютере

Нужен Python 3.12 с Tkinter. На Windows установите официальный Python с Tcl/Tk;
на Linux может потребоваться пакет `python3-tk`.

```sh
python -m venv .venv
# Linux/macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python desktop.py
# Windows вместо .venv/bin/python используйте .venv\Scripts\python.exe
```

Введите свой API ID и API Hash с my.telegram.org. Для каждого аккаунта введите
телефон, нажмите «Получить код / сессия», затем введите код Telegram и при
необходимости пароль 2FA, нажмите «Войти». Сохранённую сессию можно подключить
той же кнопкой без повторного входа. При запуске нужно подключать нужные слоты.
Вместо ввода API-параметров можно задать TG_API_ID и TG_API_HASH в окружении.

Начните с предпросмотра. Для реальной отправки включите соответствующий флажок
и запустите заново. Пауза останавливает следующие операции, но не отменяет уже
выполняющийся запрос. Аккаунты назначаются 1 → 2 → … → последний → 1 среди
подключённых слотов. Каждая находка получает отдельное предложение, в том числе
несколько подарков одного владельца. Ссылки имеют вид https://t.me/nft/Slug.

Команда: `.buy https://t.me/nft/Gift-123 95 stars` при исходной цене 100 Stars.
Цена умножается на 0.95 и округляется вниз. Лоты без цены в Stars пропускаются.
Это текстовое сообщение владельцу; приложение не выполняет оплату и не
гарантирует, что сторонний бот распознает команду в чужом личном чате.

В `watcher_core.py` сохранены коллекции и фильтры исходного трекера. Фильтр
«только один подарок от владельца» удалён из нового потока. Предпросмотр и
отправка используют разные базы, поэтому предпросмотр не блокирует отправку.
`data/` содержит сессии, журнал activity.log и SQLite-базы с назначениями и
статусами. Эти файлы приватные: не публикуйте их. Повторная отправка одного
подарка исключена и после перезапуска. Ошибки, прерванные отправки и ограничения
не повторяются автоматически: статус pending может означать неопределённый
результат при отключении во время запроса. Проверяйте чат перед ручным повтором.
При FloodWait процесс отправки останавливается без обхода через другой аккаунт.

## Проверки

```sh
.venv/bin/python -m unittest -v
```

Проверяются скидка, валюты, назначение аккаунтов, сохранение состояния и
интеграция трекера с отправкой через подменённые Telegram-клиенты. Реальный
Telegram требует ваших аккаунтов и доступ к его сети. Графический запуск требует
экрана; облачная консоль без DISPLAY не показывает окно.
