# Telegram Offers — ручная очередь без трекера

Бот принимает готовые списки. Поиск рынка, каталог и автоматический сбор владельцев удалены из этого варианта. Работа через `bot_runner.py`, графическое окно не требуется. До 10 личных аккаунтов.

## Установка и обновление

Остановите прежний процесс. Распакуйте архив в отдельную папку и перенесите в неё свою папку `data` целиком: сессии, `offers.sqlite` и историю. Не запускайте старую программу параллельно с этой версией. Базу перед обновлением рекомендуется скопировать.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-bot.txt
.venv/bin/python bot_runner.py
```

Введите API ID, API Hash и токен BotFather локально. Они не встроены в код и не записываются в настройки. Администратор по умолчанию `8957889799`; переопределяется переменной `TG_CONTROL_ADMIN_ID`. Бот принимает команды только от администратора в личном чате.

Для новой сессии (слоты 1–10):

```sh
.venv/bin/python bot_runner.py --login 1
```

Номер телефона, код и 2FA вводятся только в локальном терминале. Сохранённые сессии подключаются автоматически при запуске или командой `/connect`.

Для сервера задайте `TG_API_ID`, `TG_API_HASH`, `TG_CONTROL_BOT_TOKEN`, при необходимости `TG_CONTROL_ADMIN_ID`, затем запускайте `bot_runner.py --no-input`. Пример systemd user service находится в `deploy/`. Для постоянной работы нужен включённый компьютер или VPS.

## Ввод и проверка

Можно переслать или скопировать целиком сообщение «✅ Результаты» из парсера, включая заголовок, уровни, ссылки и статистику. Поддерживаются обычный текст Telegram и Markdown вида:

```text
✅ Результаты (14)
1. [T] [⭐ Lv.1] @recipient1 - Scared Cat (#16951) (+1)
2. [T] [Lv.0] @recipient2 - Scared Cat (#839)
```

Бот извлечёт username, название и номер NFT, затем попросит общую итоговую цену. Следующим сообщением отправьте `425 gram` (или `/price 425 gram`): эта цена подставляется в каждую команду списка. Список без цены сохраняется после перезапуска и не попадает в отправку. `/cancel` удаляет его. Пометка `(+1)` игнорируется: дополнительные NFT без явного названия и номера не добавляются. Если одна из строк списка не распознана, весь импорт отклоняется с номером строки.

После подготовки `/price 430 gram` меняет цену всех строк черновика, сохраняя ручной выбор языка. До `/enqueue` и `/run` сообщения не отправляются.

Также поддерживается прежний ручной формат:

Одна строка содержит username получателя, название NFT, номер и итоговую цену. До 100 строк в одном списке:

```text
@recipient1 Scared Cat #16951 425 gram
@recipient2 Mirage Lamp #51160 1098 gram ar
```

`recipient1` и `recipient2` замените настоящими username. Префикс `@` необязателен. Вставить `jdcsnjdc` перед названием тоже можно. Указывается готовая итоговая цена: скидка и конвертация не применяются. Поддерживаются дробные цены через точку или запятую.

По реальному отображаемому имени Telegram (имя + фамилия) бот выбирает `cn`, если есть китайские иероглифы, иначе `ar`, если есть арабские символы, иначе `ru`. При наличии обеих письменностей приоритет у `cn`. Язык в конце входной строки переопределяет автоматический выбор.

Бот показывает получателя и точную команду:

```text
jdcsnjdc Scared Cat #16951 425 gram ru
```

До отправки доступны:

- `/preview` — весь черновик.
- `/lang 1 cn` — изменить язык первой строки (`cn`, `ar`, `ru`).
- `/edit 1 @recipient1 Scared Cat #16951 425 gram ru` — заменить строку целиком.
- `/cancel` — удалить черновик.
- `/enqueue` — подтвердить черновик и добавить в очередь.
- `/run` — начать отправку подтверждённой очереди.

Пока есть черновик, новый список не затирает его. Черновик сохраняется после перезапуска. Внесение в очередь само по себе не запускает остановленный процесс отправки. Если очередь уже работает, новые подтверждённые строки добавляются в её конец.

## Очередь, история и логи

- `/pause` — приостановить / продолжить; выполняющийся Telegram-запрос может завершиться.
- `/stop` — остановить отправку, сохранив оставшуюся очередь.
- `/status` — состояния записей и процесса.
- `/accounts` — подключённые аккаунты и ограничения.
- `/logs` — последние 15 событий из постоянного журнала.

Аккаунты назначаются по кругу среди доступных слотов. Общий интервал не меньше 15 секунд между попытками, в том числе разных аккаунтов. Очередь, позиция распределения и время следующей попытки сохраняются. После перезапуска для продолжения нужен `/run`.

Общая история проверяется по Telegram user ID и username, включая историю прежнего `offers.sqlite`. Один получатель не добавляется повторно даже с другим NFT. При смене владельца username после подготовки сообщения отправка блокируется. Поэтому у каждого получателя должна быть одна строка с нужным NFT и итоговой ценой.

Статусы: `pending` — ожидает; `sending` — выполняется; `sent` — подтверждена отправка; `failed` — не отправлено; `uncertain` — результат не подтверждён. После сбоя в процессе отправки запись становится `uncertain` и автоматически не повторяется. Неудачные попытки также не повторяются автоматически. Это исключает дубли ценой возможного пропуска при неопределённом ответе Telegram.

FloodWait останавливает очередь; время ожидания указано в журнале. После него продолжайте вручную, выдержав указанный срок. PeerFlood учитывается отдельно, на третьем последовательном отказе аккаунт отключается с сохранением ограничения. Успешная отправка сбрасывает счётчик.

В `data/offers.sqlite` сохраняются история, очередь и журнал `manual_log`. События backend также пишутся в `data/activity.log`. Черновик — `data/manual_draft.json`; список, ожидающий цены, — `data/manual_import.json`. Сохраняйте `data` при обновлении. Сессии и эти файлы не включены в архив.

## Проверки

```sh
.venv/bin/python -m unittest test_manual_queue test_bot_runner -v
```

Проверки используют подменённые Telegram-клиенты и не отправляют сообщения. Живая проверка требует ваших ключей и подключения к Telegram.
